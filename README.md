## 📢 Weekly Stand Up

### Week 1 — Project Foundation

**⚙️ Overview:** Planned Mage's Chess, a chess game with elemental abilities. Established the project's class structure and basic board representation.

**🌵 Challenges:** Designing the game so traditional chess rules and elemental abilities could work together without making the code overly complicated.

**🏆 Accomplishments:** Improved my understanding of object-oriented design and separating responsibilities between classes.

**🔮 Next Steps:** Implement traditional chess movement, turn management, and move validation.

### Week 2 — Chess Mechanics

**⚙️ Overview:** Implemented traditional chess gameplay, including piece movement, captures, check detection, and special moves.

**🌵 Challenges:** Handling complex rules like castling, en passant, and preventing moves that leave the king in check.

**🏆 Accomplishments:** Gained experience implementing game logic, validating player input, and debugging interconnected systems.

**🔮 Next Steps:** Add elemental enchantments, mana management, and improve player controls.

### Week 3 — Elemental Gameplay

**⚙️ Overview:** Implemented Scorch, River, and Zephyr enchantments, along with mana costs and cooldowns. Added keyboard navigation and improved the console interface.

**🌵 Challenges:** Ensuring enchanted moves followed their unique rules without breaking traditional chess mechanics. Also encountered console rendering and layout issues.

**🏆 Accomplishments:** Improved my ability to integrate new features into existing code and troubleshoot console rendering.

**🔮 Next Steps:** Implement save/load functionality, polish the interface, and prepare the game for final testing.

### Week 4 — Finalization and Polish

**⚙️ Overview:** Added save/load functionality, improved the interface with color-coded information and move highlights, and created a dedicated game-over screen.

**🌵 Challenges:** Resolving input handling and compilation issues while preserving the existing interface layout.

**🏆 Accomplishments:** Gained experience with file I/O, game-state serialization, debugging, and improving the overall user experience.

**🔮 Next Steps:** Complete final gameplay testing, address any remaining bugs, and prepare Mage's Chess for submission.
